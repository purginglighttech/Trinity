# Project website concept — held for release ideas

Stated by Chris, 2026-11-18 (~03:02 PT, main chat). Status: concept held, no mockup wanted yet.

## The concept

- **Big banner at the top:** "Don't trust my claims about the system, examine it yourself"
- **Then just links** to the documentation and sources of the projects.
- Nothing else: no marketing copy, no feature tour, no funnel.

## Why it fits (from the same conversation)

- It is the credo as a web page: "Don't trust the system trust the source" (2026-11-17), sharpened — the banner doesn't ask visitors to trust the source either, only to examine it.
- The page practices what it preaches: a visitor can't be sold by it, only convinced by their own audit.
- Matches Chris's standing web preferences: basic, functional, no gratuitous animation; "Just the Facts" for techs.
- Pairs with the adopted release-notes standard (2026-11-17): every claim carries its proof, walkable back into the source.
